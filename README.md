# MagicBorder


Локальное настольное приложение на Python и `PyQt5` для работы с фотографиями листьев растений. Приложение работает с проектами: в одном проекте можно хранить набор растровых изображений, их контурные аннотации, сведения об условиях съёмки и сводную статистику в общем `json`-файле.

## Возможности

- создание, открытие, сохранение и закрытие проектов с отдельной папкой проекта;
- пакетное добавление изображений `png`, `jpg`, `jpeg`, `bmp`, `tif`, `tiff` в папку проекта;
- предложение уменьшить большие фотографии (от 2560×1920) до 1920×1080, 1280×720, 800×600 или 600×450 при добавлении и синхронизации: в проект записывается уменьшенная копия с сохранением пропорций, EXIF и ICC-профиля, обработка идёт в фоновых потоках с индикатором прогресса;
- хранение списка изображений и аннотаций в одном сгруппированном JSON-файле проекта;
- левая панель проекта со списком изображений и сгруппированными свойствами выбранного файла;
- редактируемые метаданные изображения: дата добавления, дата съёмки с диалогом выбора даты/времени, условия съёмки, координаты, диагноз и заметки;
- единый GUID изображения с проверкой уникальности, ручным редактированием и кнопкой генерации нового ID;
- переименование файла изображения по текущему ID с сохранением расширения;
- синхронизация папки изображений проекта: добавление в JSON файлов, уже лежащих в `images`, но отсутствующих в списке проекта;
- экспорт списка изображений проекта в Excel `.xlsx`;
- удаление изображений из проекта;
- экспорт свойств выбранного изображения в Excel `.xlsx`;
- отображение выбранного изображения проекта на канвасе;
- фиксированная светлая тема интерфейса;
- масштабирование: увеличить, уменьшить, показать целиком, 100%;
- SVG-иконки для всех команд меню и панели инструментов;
- автоматическое выделение контура листа;
- создание стартового окружного контура с заданным количеством узлов;
- выравнивание фона: всё вне текущего контура становится белым;
- ручное редактирование узлов контура;
- добавление узлов двойным щелчком по сегменту;
- удаление узлов правой кнопкой мыши или клавишей `Delete`;
- автоматическое сохранение контура выбранного изображения в JSON проекта;
- ручное обновление гистограмм и аналитики кнопкой «Обновить» (`Вид -> Обновить`, `F9`): фотографии загружаются без пересчёта графиков.

## Запуск через uv

```bash
uv sync
uv run magicborder
```

Альтернативный запуск:

```bash
uv run python -m magicborder.main
```

На Windows используйте те же команды в PowerShell из корня проекта:

```powershell
uv sync
uv run magicborder
```

После установки пакета доступен также GUI-entrypoint `magicborder-gui`, который на Windows создаётся как оконный launcher без привязки к Unix-пути `.venv/bin`.

## Как пользоваться

1. Создайте проект через `Файл -> Новый проект` или откройте существующий через `Файл -> Открыть проект`.
2. Добавьте одно или несколько изображений через `Файл -> Добавить изображения`.
3. Если изображения уже вручную помещены в папку `images`, используйте `Файл -> Синхронизировать папку изображений`.
4. Выберите изображение в левой панели проекта.
5. При необходимости отредактируйте свойства изображения, ID и сведения в группах нижней части левой панели.
6. Запустите `Инструменты -> Определить контур` или создайте стартовый контур через `Инструменты -> Новый контур`.
7. Перемещайте узлы мышью для корректировки.
8. Дважды щёлкните рядом с сегментом, чтобы добавить новый узел.
9. Удалите выбранный узел клавишей `Delete` или правой кнопкой мыши по узлу.
10. Изменения контура автоматически записываются в JSON проекта.
11. Нажмите «Обновить» в правой панели (или `Вид -> Обновить`, `F9`), чтобы пересчитать гистограммы,
    средние цвета изображения и сводную статистику проекта.
12. При необходимости используйте `Файл -> Сохранить проект`.

Приложение работает через проектный сценарий: изображения открываются на канвасе только после добавления в проект или синхронизации из папки `images`.

### Обновление графиков

Гистограммы и средние цвета не пересчитываются автоматически: выбор изображения, создание и правка контура
только помечают аналитику как устаревшую (в заголовке правой панели появляется «Данные устарели», а в полях
свойств — «нажмите «Обновить»»). Расчёт запускается кнопкой «Обновить» в правой панели, командой
`Вид -> Обновить`, кнопкой на панели инструментов или клавишей `F9`. Благодаря этому загрузка фотографий
проходит без задержек на обработку пикселей.

## Проекты

При создании проекта приложение сначала спрашивает имя проекта, затем предлагает выбрать родительскую папку. Внутри выбранной папки создаётся отдельная папка проекта:

```text
<выбранная папка>/
└── <имя проекта>/
    ├── images/
    └── <имя проекта>.json
```

Если итоговая папка проекта уже существует и не пуста, приложение не перезаписывает её содержимое и предлагает выбрать другое имя проекта или пустую папку.

## ID Изображения

У каждого изображения есть один канонический ID: поле `file.id` в записи проекта. Для новых изображений он создаётся как UUID4/GUID в формате `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`.

Этот ID:

- отображается и редактируется в поле `ID` окна свойств;
- используется как значение колонки `ID изображения` при экспорте списка в Excel;
- может быть пересоздан кнопкой генерации ID;
- может использоваться для переименования файла изображения по ID.

Формат проекта версии 2 использует сгруппированные записи изображений и не выполняет миграцию старых плоских записей проекта.

## Формат JSON проекта

В JSON проекта каждое изображение хранится группами:

```json
{
  "file": {
    "id": "uuid",
    "path": "images/leaf.png",
    "display_name": "leaf.png",
    "image_size": { "width": 1200, "height": 800 },
    "added_at": "2026-05-07T10:20:30+03:00",
    "captured_at": ""
  },
  "contour": {
    "annotation": null
  },
  "location": {
    "illumination": "",
    "humidity": "",
    "wind_speed": "",
    "wind_direction": "",
    "latitude": "",
    "longitude": ""
  },
  "details": {
    "diagnosis": "Не указано",
    "notes": ""
  }
}
```

Вычисляемые свойства, например средний RGB-цвет и количество пикселов контура, не сохраняются в JSON проекта: они рассчитываются по изображению и текущей аннотации при отображении или экспорте.

## Синхронизация Изображений

Команда `Файл -> Синхронизировать папку изображений` сканирует папку `images` текущего проекта и добавляет в JSON совместимые растровые файлы, которых ещё нет в списке проекта. Команда работает рекурсивно внутри папки изображений, не копирует файлы из других мест и не строит автоматический контур для новых записей.

Для каждого добавленного файла создаётся запись с новым GUID, относительным путём, именем файла, размером изображения и группами сведений по умолчанию. Уже учтённые файлы не дублируются, неподдерживаемые расширения игнорируются, а повреждённые изображения пропускаются с предупреждением.

## Экспорт списка в Excel

Команда `Файл -> Экспорт списка в Excel` сначала открывает диалог выбора столбцов, а затем сохраняет список изображений проекта в файл `.xlsx`. В диалоге можно оставить все столбцы или выбрать только нужные: ID изображения, имя файла, относительный путь, наличие аннотации, статус, диагноз, средние значения RGB внутри контура и количество пикселов контура.

В Excel заголовки столбцов выводятся на русском языке. Если файл отсутствует или у изображения нет контура, строка всё равно добавляется, а статистические поля остаются пустыми.

## Экспорт свойств изображения в Excel

Команда `Файл -> Экспорт свойств изображения в Excel` сохраняет свойства текущего выбранного изображения проекта в файл `.xlsx`. Та же команда доступна кнопкой `Excel` в верхней части панели `Свойства изображения`.

Перед сохранением открывается диалог выбора свойств с чекбоксами. По умолчанию выбраны все свойства, сгруппированные как на панели: общая информация о файле, информация о контуре, цветовая схема RGB, локация и дополнительные сведения. В Excel данные выводятся вертикально: первая строка содержит русские заголовки `Свойство` и `Значение`, а каждое выбранное свойство занимает отдельную строку.

## Архитектура

- `main_window.py` отвечает за главное окно, меню, панель инструментов и пользовательские команды.
- `icons.py` содержит подключение SVG-иконок, всплывающие подсказки и визуальные метаданные действий.
- `canvas.py` реализует канвас на базе `QGraphicsView`, отображение изображения, контура и редактируемых узлов.
- `detector.py` содержит алгоритм автоматического определения контура листа.
- `models.py` описывает модели аннотации, проекта и формат сериализации.
- `io_utils.py` отвечает за загрузку изображений и чтение/запись `json` аннотаций и проектов.

## Примечание по алгоритму

Автоматическое выделение контура реализовано как практичный MVP: сначала используется `GrabCut`, затем при необходимости включается резервная цветовая сегментация и очистка маски. Такой подход хорошо подходит для локального настольного инструмента и оставляет пространство для дальнейшего улучшения алгоритма.
